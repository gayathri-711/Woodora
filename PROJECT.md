# WOODORA – Premium Furniture E-Commerce Project

## 1. Project Overview

**WOODORA** is a luxury furniture and interior design e-commerce website crafted with timeless elegance, modern Scandinavian and European artisanal aesthetics, sustainable materials, and a seamless shopping experience.

- **Brand Name**: WOODORA
- **Tagline**: Crafted for Comfort. Designed for Life.
- **Industry**: Furniture, Interior Design & Home Living
- **Brand Personality**: Premium, elegant, natural, sophisticated, and trustworthy.

## 2. Design System & Theme

- **Primary Color**: Forest Green (`#263D32`)
- **Secondary Color**: Warm Cream (`#F7F4EE`)
- **Accent Color**: Walnut Brown (`#805B42`)
- **Beige Neutral**: Soft Beige (`#E8DED0`)
- **Text Color**: Dark Charcoal (`#252525`)
- **Gold Highlight**: Antique Gold (`#C8A882`)
- **Typography**: Playfair Display (Serif Headings), Cormorant Garamond, Plus Jakarta Sans (Clean UI Body), Jost

## 3. Key Modules & Features

- **Homepage**: 16-part luxury experience with announcement bar, hero carousel, category showcase, bestsellers, new arrivals, promotional craftsmanship banner, about brand story, value propositions, interior design lookbooks, verified customer testimonials, newsletter privilege, and comprehensive footer.
- **Product Catalog (Shop)**: Interactive filtering by 8 categories (Sofas, Chairs, Beds, Dining Tables, Wardrobes, Coffee Tables, Office Furniture, Home Decor), real-time price range slider, instant keyword search, sorting (low/high/A-Z), quick add to cart, and wishlist heart toggles.
- **Product Details**: Multi-angle gallery with thumbnail switcher, dimensions and materials specifications, interactive color swatches, size selector, quantity adjuster, Add to Cart, Wishlist, and related furniture recommendations.
- **Shopping Cart**: Real-time interactive cart with local storage persistence, quantity adjustment (+/-), smooth item removal, coupon promo code engine (`WOODORA10`), auto-calculation of subtotal, 5% tax, shipping (Free over $250 or $15), and grand total.
- **Checkout Workflow**: Two-column billing/shipping address form with validation, live order review table, payment method selector (Credit Card, Apple Pay / Google Pay, Bank Transfer, Cash on Delivery), and order placement.
- **Order Confirmation**: Branded Thank You page with dynamically generated Order ID, delivery estimate, and order details.
- **Showroom & Interior Consultation Booking**: Dedicated appointment booking modal and forms for customized interior design guidance.
- **Backend & Forms**: PHP contact endpoint (`contact-form.php`) with sanitized input handling and AJAX validation.

## 4. Technology Stack

- **Frontend**: HTML5, CSS3, JavaScript (ES6+), jQuery 3.7.1, Bootstrap 4, Font Awesome 6.5.1, Owl Carousel, AOS animations, Magnific Popup
- **Custom Styling**: `woodora.css` (Brand variables, luxury product cards, toast notifications, responsive rules)
- **Custom Logic**: `woodora.js` (E-Commerce cart state engine, catalog filtering, wishlist, toast alerts)
- **Backend**: PHP contact form processing (`contact-form.php`)
- **Assets**: Custom SVG vector & PNG logos, high-resolution responsive furniture photography, custom favicons
